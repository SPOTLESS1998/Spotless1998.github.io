## What I build

Autonomous agents and the systems around them: retrieval-augmented generation
for grounded answers, multilingual service agents, and outbound pipelines that
draft every message and hold it for human approval before anything is sent.

Most of it is public:

| Project | What it is |

## Working conventions

- Agents draft. A human approves before anything is sent or posted.
- Anything scraped from the web is sanitized before it reaches a model.
- Lead data is never committed.
